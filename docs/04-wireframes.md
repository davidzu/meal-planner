## Low-fi rules (keep iterations fast)

1. Grayscale only. No brand colors, no real fonts, no images.
2. Real content, not lorem ipsum: use actual recipes ("Birria", not "Recipe 1") and Spanish meal labels.
3. Every frame gets 2–5 annotation callouts (yellow notes) explaining behavior, numbered to match screen-spec acceptance criteria.
4. One frame per screen state that matters (e.g., WeekGrid: empty / partial / full).
